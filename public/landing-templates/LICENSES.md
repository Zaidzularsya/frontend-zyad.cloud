# Lisensi aset Galeri Template

**Aturan:** file di folder ini tidak pernah diubah isi atau namanya dan tidak pernah dihapus, karena halaman tenant yang sudah memakai template merujuknya lewat path. Revisi berarti file baru dengan sufiks versi (`-v2`).

## Ilustrasi (`<slug>/*-v1.svg`)

Semua gambar contoh di folder template adalah **ilustrasi orisinal** yang dibuat untuk proyek Zyad (bentuk geometris vektor, bukan foto dan bukan turunan karya pihak lain). Tenant mengganti gambar-gambar ini dengan fotonya sendiri lewat Asset Manager. Tidak ada pembatasan pihak ketiga.
